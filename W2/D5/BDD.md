# BDD: день 10

Реализация основана на отдельной копии дня 9 в пакете agent10. Новые сценарии написаны до реализации, предыдущие регрессии сохранены.

1. RED: новые `features/strategies.feature` и `test_strategies.py` завершились `ModuleNotFoundError: agent10.strategies`.
2. GREEN: выбор контекста, Sticky Facts, SQLite v4, checkpoint и fork.
3. RED: тесты интерфейса обнаружили отсутствие трёх стратегий и кнопок ветвления; затем появились переключатели и просмотр памяти.
4. RED: тесты нового отчёта падали на старой структуре (`KeyError: memory`) и отсутствующей функции complexity.
5. GREEN: три режима, учёт обслуживания, одинаковый архив, независимые вопросы, проверка веток и полный HTTP-мок эксперимента.
6. RED: проверка журнала обнаружила отсутствие явных событий SOURCE_IMPORT, CHECKPOINT и FORK в утилите эксперимента; события добавлены.
7. Реальный первый прогон выявил, что экстрактор facts иногда отвечает на вложенный вопрос вместо обновления памяти. Система отклонила неправильный результат и сохранила старое состояние.
8. RED: отдельный тест воспроизвёл запрос facts с вложенным форматом `value`; обязательная JSON Schema отсутствовала.
9. GREEN: провайдер и маршрут проверяются на json_schema_strict, для экстрактора задана строгая схема списка пар, локальная валидация проверяет типы и дубликаты. Добавлен тест на ответ `{value: ...}` вместо facts.

| Дано | Когда | Тогда |
|---|---|---|
| Полный архив | Sliding Window выбирает контекст | Старый префикс отсутствует в запросе, архив неизменен |
| Два последовательных инструмента | Граница окна пересекает ход | Вызовы и результаты сохраняются целой группой |
| Новое сообщение пользователя | Режим facts | До основного ответа выполняется отдельная экстракция |
| Исправленный бюджет | Обновление facts | Актуальное значение заменяет прежнее |
| Переключение из другой стратегии | Первый запрос summary | Старый префикс сжимается до основного ответа, архив сохраняется |
| Переключение из другой стратегии | Первый запрос facts | Обрабатываются все пропущенные пользовательские сообщения |
| Вопрос с собственным форматом JSON | Экстрактор facts | Использует свою строгую схему, не формат вложенного вопроса |
| Неверный JSON, дубликаты, числа вместо строк | Обновление facts | Старые память и архив сохраняются, основной ответ не генерируется |
| Timeout, disconnect, HTTP 503, length | Вызов экстрактора | Один запрос, ошибка и расход учтены, скрытых повторов нет |
| Бюджета не хватает | Обновление facts | HTTP не отправляется, локальная блокировка записана |
| Facts обновлены, основной ответ упал | Завершение хода | Новые facts и ход не фиксируются отдельно друг от друга |
| Два fork одного checkpoint | Разные продолжения | Состояния веток различаются, родитель и checkpoint неизменны |
| Ошибка SQLite при вставке branch | Создание ветки | Все новые строки откатываются |
| Незавершённый ход | Сохранение checkpoint | Операция отклонена |
| Повреждённый checkpoint | Fork | Ветка не создаётся, источник остаётся доступным |
| Перезапуск | Загрузка диалогов | Сохраняются архив, summary, facts и независимость веток |
| SQLite v1/v2/v3 | Миграция | Прежние данные и сводки сохраняются |
| Один архив и десять эталонов | Сравнение стратегий | 30 независимых вопросов, учтены все вызовы обслуживания |

Тесты используют HTTP-моки и временные базы, платные запросы не выполняют. Реальные ответы и промежуточный остановленный прогон сохраняются отдельно для проверки выводов.
