# Видео дня 7 · Сохранение контекста

Ориентир 3–5 минут. Не показывайте .env и личные журналы. Используйте новый
учебный разговор. Все отправленные модели сообщения тарифицируются.

1. Покажите BDD.md и запустите тесты:

```bash
cd /Users/brestkin/ai-advent-challenge-10/W2/D2
.venv/bin/python -m pytest -v
```

Скажите «Сначала написаны сценарии сохранения и восстановления. Тесты проверяют
полный стек сообщений, связь tool_call_id, перезапуск и обработку сбоев».

2. Запустите сервер в этом же терминале:

```bash
.venv/bin/agent7
```

Откройте http://127.0.0.1:8061. Если сервер уже работает, остановите его в терминале
и запустите эту команду. Для одной базы предусмотрен один процесс сервера.

3. Создайте новый разговор и отправьте:

«Запомни: проект называется Маяк, менеджер Ирина. Найди сумму заказа A-104».

Дождитесь ответа 2390 RUB и результата find_order. Откройте панель «Сохранённый
контекст», покажите assistant с tool_calls и tool с соответствующим ID.

4. В терминале нажмите Ctrl+C. Покажите завершение процесса. Затем снова:

```bash
.venv/bin/agent7
```

Обновите страницу браузера. Покажите статус «Разговор восстановлен из SQLite»,
прежнее сообщение, ответ и результат инструмента. При необходимости выберите
разговор слева. Скажите «Сервер действительно был остановлен. Разговор загрузился
из файла data/history.sqlite3, включая исходный протокол вызова инструмента».

5. В том же разговоре отправьте:

«Напомни название проекта, имя менеджера и ранее найденную сумму заказа.
Используй сохранённую историю, без повторного поиска».

Покажите ответ Маяк / Ирина / 2390 RUB и отсутствие новых инструментов в этом ходе.

6. Коротко покажите store.py: таблицы sessions/attempts и атомарный complete().
В Agent.run() покажите добавление tool_call_id. В web.py — загрузку messages
перед продолжением разговора.

Короткая речь для вывода:

«Агент сохраняет полный диалог в SQLite вместе с вызовами инструментов и их
результатами. После остановки и нового запуска он восстановил прежнюю историю
и вспомнил проект, менеджера и сумму заказа без повторного поиска.
Незавершённые попытки записываются отдельно. Контекст сейчас передаётся целиком,
поэтому в следующем задании измерю, как растут токены и стоимость».

Для воспроизводимой автоматизированной проверки можно дополнительно выполнить:

```bash
.venv/bin/python -m agent7.restart_pilot
```

Runner сам останавливает первый процесс и поднимает второй с той же изолированной
базой. Код 0 означает успех всех проверок, код 1 — ошибка. Путь к отчёту выводится
в терминал. В submission/ лежат результаты уже выполненного реального прогона.
