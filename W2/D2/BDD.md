# BDD · День 7

1. Сначала перенесены 46 проверок D6 в пакет agent7 и добавлены сценарии
   хранения/восстановления. Первый запуск — ModuleNotFoundError: agent7.
2. Добавлены SQLite Store, сохранение промежуточных попыток, восстановление
   веб-сессий и полный протокол. Первый зелёный запуск — 57 тестов.
3. Три новых красных теста показали приём неверных tool_calls (словарь, число,
   строка) из повреждённого контекста. После исправления проверяется тип списка.
4. Новый тест показал, что provider message без role не приводится к assistant.
   Исправление добавляет роль при её отсутствии и сохраняет остальные метаданные.
5. Проверка реального рестарт-пилота сначала упала на отсутствии restart_pilot.
   Добавлены проверка точной истории и контрольные детали, затем runner двух
   отдельных HTTP-процессов. Подмена tool ID и потеря деталей обнаруживаются тестом.
6. Красный тест --help показал отсутствие CLI-журнала. Справка и ошибки аргументов
   теперь записываются через Journal с маскированием ключа.

7. Два красных теста выявили приём неверного списка tool_calls агентом и
   необработанный ValueError при сохранении неверного протокола. Теперь агент
   отклоняет неверный список, а хранилище возвращает StoreError без изменения истории.

Итого 70 зелёных офлайн-тестов. Включены таймауты, сетевые и HTTP-ошибки,
обрезание, лимиты, неверные инструменты/аргументы, повреждённая база и JSON,
неподдерживаемая версия, смена профиля, сбои checkpoint/commit, изоляция сессий,
защита от второго сервера, восстановление после трёх запусков, маскирование ключа.

Отдельный платный пилот подтвердил восстановление между процессами 3194 и 3200.
Сравнение before.messages == restored.messages прошло. В новом запросе весь
старый протокол присутствует перед новым user-сообщением, инструменты повторно
не вызывались. Проверка браузера отдельно включает остановку сервера и обновление
страницы с восстановлением выбранной сессии из SQLite.
