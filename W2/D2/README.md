# День 7 · Сохранение контекста · W2/D2

Агент сохраняет полный диалог в SQLite и восстанавливает его после перезапуска
HTTP-сервера. В базе остаются сообщения пользователя, assistant-сообщения
с tool_calls, результаты tool с tool_call_id и дополнительные метаданные API.
Системная инструкция, определения инструментов, модель и настройки хранятся
в профиле разговора. При продолжении весь успешный диалог отправляется модели.

## Запуск

```bash
cd /Users/brestkin/ai-advent-challenge-10/W2/D2
.venv/bin/agent7
```

Откройте http://127.0.0.1:8061. Порт D7 — 8061, D6 — 8060.
Для остановки нажмите Ctrl+C в терминале сервера. Запустите ту же команду
и обновите страницу. Выбранный разговор загрузится из SQLite автоматически.
На другом браузере выберите его в списке разговоров.

База по умолчанию — `data/history.sqlite3` внутри W2/D2. Путь привязан к папке
проекта и не зависит от текущего каталога терминала. Имя выбранного разговора
браузер хранит в localStorage, сам контекст находится на сервере в SQLite.
Кнопка «Новый разговор» создаёт независимую сессию. Справа раскрывается
«Сохранённый контекст» с точным стеком сообщений, включая tool_calls/tool.

Для новой установки:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install -e '.[test]'
```

В текущей рабочей копии окружение установлено. Используется Python 3.9+,
SQLite входит в Python. Процессная блокировка реализована для macOS/Linux.
Ключ POLZA_API_KEY читается из .env W1/D1 → D2 → D3 → D4 → D5 → W2/D1 → W2/D2
→ окружение. Поздние значения перекрывают ранние, включая пустые.
Модель — google/gemini-2.5-flash-lite, маршрут — google-ai-studio/flex.

## Практическая проверка

1. В новом разговоре отправьте «Запомни: проект называется Маяк, менеджер Ирина.
   Найди сумму заказа A-104».
2. Дождитесь результата find_order и финального ответа с суммой 2390 RUB.
3. Остановите сервер Ctrl+C. Запустите его заново с той же базой.
4. Обновите страницу. Проверьте прежние сообщения и результат инструмента.
5. Спросите «Напомни название проекта, имя менеджера и ранее найденную сумму
   заказа. Используй сохранённую историю, без повторного поиска».
6. Ожидаются Маяк, Ирина и 2390 RUB. В проверенном прогоне нового вызова
   инструмента не было, ответ сформирован из восстановленного контекста.

Автоматизированная реальная проверка запускает и останавливает два отдельных
процесса сервера с одной изолированной базой:

```bash
.venv/bin/python -m agent7.restart_pilot
```

Это платные запросы к Polza.ai. База проверки и отчёт создаются в новой папке
`results/<дата_id>/`, личные разговоры из data/ не используются. В проверенном
прогоне выполнены три API-вызова, известная стоимость 0.01334412 ₽.
Процессы 3194 и 3200, все семь проверок успешны. Результаты для сдачи — submission/.
`agent7.pilot` также сохраняет проверку инструментов D6, её файлы pilot.json/trace.json
отличаются от материалов проверки перезапуска restart.json/restart-trace.json.

## Целостность данных и ошибки

`store.py` хранит sessions и attempts, PRAGMA user_version=1. У каждого разговора
есть профиль и revision. Модель, параметры, системная инструкция и инструменты
проверяются перед продолжением. Смена профиля требует отдельного разговора.
История W2/D1 находилась только в памяти и автоматически в D7 не переносится.

На успешном ходе один COMMIT сохраняет полный протокол, отображаемые сообщения,
новую revision и статус попытки. После каждого ответа модели и результата
инструмента сохраняется промежуточный снимок попытки. При ошибке API успешная
история остаётся прежней, частичная попытка и причина сбоя сохраняются отдельно.
При запуске running-попытки помечаются interrupted. Их вызовы не переисполняются.
Для продолжения используется последний успешно сохранённый контекст, интерфейс
показывает наличие незавершённых попыток. После сбоя записи проверьте историю
перед ручной повторной отправкой, поскольку запрос мог уже тарифицироваться.

Повреждённые БД, неизвестная версия схемы и неверный tool-протокол останавливают
работу с соответствующими данными. Файл не заменяется новой пустой базой.
Одну базу обслуживает один сервер, повторное открытие вторым процессом отклоняется.
HTTP-запросы чата сериализованы. SQLite использует WAL и synchronous=FULL.
Файлы базы и lock создаются с правами 600, новый каталог данных — 700.

Все запросы к LLM по-прежнему используют HTTP-клиент и tool_choice=auto.
Инструменты find_order и calculate сохранены. Лимит — шесть обращений к модели
за ход и до четырёх инструментов на ответ. Подключение — 10 секунд, ожидание
данных — 180 секунд. Автоматические повторы отключены.

Дополнительные параметры запуска:

```bash
.venv/bin/agent7 --port 8063 --data-dir /абсолютный/путь/к/данным
```

Также поддерживается AGENT7_DATA_DIR. При изменении пути приложение откроет
другую базу. Полная история пока отправляется без сжатия и усечения.

## Тесты, журнал и сдача

```bash
.venv/bin/python -m pytest -v
```

70 офлайн-тестов. BDD-сценарии написаны до реализации, цикл red → green — BDD.md.
Проверяются перезапуск, точное восстановление метаданных, независимость сессий,
ошибки сети, записи и схемы, ключи, журнал и прежние сценарии инструментов.

Каждый запуск создаёт UTF-8 logs/YYYY-MM-DD_HH-MM-SS_id.log. Запуск через CLI
пишет журнал аргументов/справки и отдельный журнал HTTP-сервера. Записаны запросы,
ответы, инструменты, usage, сохранение/восстановление истории и ошибки.
Ключ маскируется, Authorization не сохраняется. Журнал, база и браузерное
представление содержат текст разговора. При отказе журнала работа прекращается.

.gitignore исключает личные data/, results/, .env, .venv и *.log. Для репозитория
подготовлены код, тесты, документация и проверенные учебные JSON из submission/.
Видео ещё требуется записать. VIDEO.md содержит команды и короткую речь.
