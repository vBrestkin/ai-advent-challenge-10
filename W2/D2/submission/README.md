# Материалы сдачи дня 7

Откройте report.md для результата проверки. Реальный перезапуск подтверждён
разными PID процессов, точным совпадением messages и ответом после восстановления.

restart.json содержит снимки до остановки, после загрузки и после продолжения.
restart-trace.json содержит только фиксированные учебные запросы этого пилота,
с указанием фаз before/after. metrics.json содержит usage трёх API-вызовов.

Код, автотесты, BDD.md и VIDEO.md находятся в родительской папке W2/D2.
Личные SQLite-базы и .log в комплект не входят.
