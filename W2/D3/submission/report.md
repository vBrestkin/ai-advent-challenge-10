## Выводы и условия

- Каждый новый запрос передаёт всю историю, системную инструкцию, схемы инструментов и результаты их вызовов.
- Локальный подсчёт текста использует фиксированный токенизатор Qwen. Оценка полного запроса токенизирует JSON, она отличается от серверного оформления ролей и инструментов. Фактические prompt/completion/total берутся из usage API.
- Метрики хода суммируют все обращения к LLM, включая этапы вызова инструментов. Reasoning уже входит в completion и total.
- Для long используется один растущий разговор. short и pilot_tools начинают независимые разговоры. Переполнение проверяется на продолжении long, поэтому можно проверить сохранность прежней истории.
- В лабораторной проверке overflow явно разрешён выход за локальную оценку. Ошибка локального ограничителя local_guard показывается отдельно. HTTP 400 провайдера и HTTP 502 приложения сохранены раздельно.
- При ошибке успешный контекст не дополняется незавершённым ходом. Сам запрос и метрики остаются в attempts/calls.
- Отсутствующий usage не означает бесплатный вызов. При неизвестном списании сохраняется резерв, он не подставляется вместо фактической цены.
- Сжатие и усечение истории отключены. Порядок запросов фиксирован, автоматических повторов и fallback нет.

## Наблюдения подготовленного прогона

В short получены 844 входных и 33 выходных токена. В long восемь новых
сообщений содержали по 1737 локальных токенов. Вход одного API-запроса вырос
с 2567 до 14831, а стоимость хода с 0.03651768 до 0.21017138 ₽. Ответы
оставались короткими, по 6 токенов. Всего long потребовал 69592 входных
токена и 48 выходных, известная стоимость 0.98675627 ₽.

Рост связан с повторной отправкой всего накопленного диалога. Локальный
размер текущей истории описывает один стек сообщений. Накопленный вход API
суммирует повторно передаваемые части во всех обращениях.

Overflow содержал 50018 токенов нового текста по закреплённому токенизатору.
JSON всего запроса оценён в 64334. В ответе Polza.ai указана собственная
приблизительная оценка ~86744, код BAD_REQUEST и reason=inputExceedsContext.
Отказ произошёл на шлюзе. Фактический usage отказавшего запроса не возвращён,
поэтому число ~86744 не подставлялось в prompt_tokens и стоимость не обнулялась.

Успешная история до и после overflow совпала. Повторная проверка local_guard
остановила запрос на стороне приложения, без HTTP-вызова к LLM.

Пилот инструментов потребовал три обращения и дал ответ 2031.50 RUB. Всего
эксперимент включил 13 отправленных HTTP-запросов и одну локально остановленную
попытку. Известная стоимость 1.04134164 ₽, одно неизвестное списание с резервом
5.7407720321 ₽. Учтено 6.7821136721 ₽ из 20 ₽.

Тарифы и параметры зафиксированы в catalog.json. Токенизатор взят из официального
репозитория Qwen на ModelScope, источник и SHA-256 приведены в tokenizer-info.json.
В успешных ответах API сообщил 0 reasoning-токенов. Запрашивалось reasoning.enabled=false.
Дополнительная проверка интерфейса в браузере не входит в таблицу эксперимента,
три обращения стоили около 0.042 ₽. Вместе с этой проверкой учтено менее 6.83 ₽.

Все 98 офлайн-тестов проходят. Подготовлен сценарий видео, запись ещё требуется.
