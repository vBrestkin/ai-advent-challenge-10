# BDD · День 8

Исходные 70 проверок агента, инструментов, SQLite и перезапуска перенесены
в самостоятельный пакет agent8. До реализации написаны новые поведенческие
тесты локального счётчика, usage, агрегирования, бюджета, метрик инструментов,
сохранения ошибок и миграции. Первый запуск — ModuleNotFoundError: agent8.

## Основные новые сценарии

- Дано сообщение и история с инструментами. Когда подготовлен запрос,
  считаются новый текст, история и полный запрос со схемами. Оценка отделена от API.
- Даны два обращения к LLM в одном ходе. Когда ход завершён, метрики обоих
  обращений суммируются, reasoning повторно к total не прибавляется.
- Дано сохранённое usage. После перезапуска новый экземпляр приложения
  загружает те же записи calls и суммы, локальная оценка не вызывает LLM.
- Дано переполнение. Обычный запрос блокируется до HTTP. Лабораторный режим
  отправляет запрос и сохраняет реальный отказ API. История остаётся прежней.
- Дана база v1. При открытии создаётся схема v2, полный протокол сохраняется.
- Дано неизвестное списание. В бюджете остаётся резерв, стоимость не становится нулём.

После основных модулей прошли 86 тестов. До модулей установки и эксперимента
написаны тесты атомарной установки, проверки SHA-256, отчёта и различия локальной
блокировки с отказом API. Красный этап — ModuleNotFoundError: setup_tokenizer.

Полный эксперимент дополнительно проверен через HTTP и MockTransport:
пилот инструментов, short, восемь long, overflow и local_guard. 12 пользовательских
попыток, 13 отправленных HTTP-вызовов. Локальная блокировка не засчитывается
как отказ провайдера. После этого этапа прошли 90 тестов.

Красные тесты --help обнаружили отсутствие журнала у experiment и нежелательную
загрузку токенизатора при --help. Введён общий LoggingParser. После исправления
92 теста проходили. Тест пустой истории затем обнаружил ненулевой счётчик из-за
JSON-конверта, исправлено на 0 для пустой истории. Проверен настоящий путь загрузки
локального токенизатора на тестовом словаре и отказ при изменении SHA-256.
Тест лимита completion обнаружил неполную проверку каталога, она дополнена.

Итого 98 офлайн-тестов. Реальный запуск API проводился отдельно. Ошибка Polza.ai
400 inputExceedsContext сохранена как ответ шлюза с неизвестным usage. Незавершённый
ход не добавился к успешной истории. Обход локальной проверки используется
только лабораторным runner, на фактических данных этого запуска не требовались
повторы запросов.

Проверка браузера выявила отображение одного токена для пустого редактора из-за
подстановки пробела. Добавлен красный тест: estimate принимает пустой текст
с результатом 0, chat по-прежнему отклоняет пустое сообщение. Выделена схема
EstimateRequest, подстановка пробела удалена. На этом этапе — 96 тестов.

Два новых красных теста обнаружили сбой записи SQLite при NaN и 1e999 в сыром
usage. Добавлена проверка конечности всего JSON до сохранения словаря ответа.
Некорректный ответ остаётся исходным текстом, статус api_error, цена неизвестна,
успешная история сохранена. Итог — 98 тестов.
