# BDD: день 9

Сохранены регрессионные сценарии агента, SQLite и метрик из дня 8. Новые спецификации появились до изменения реализации.

1. RED: `test_compression.py` + `features/compression.feature`; первый запуск завершился `ModuleNotFoundError: agent9.memory`.
2. GREEN: реализованы неизменяемая Memory, безопасная граница префикса, обновление и выбор контекста; затем интеграция с Agent и SQLite.
3. RED: тесты нового эксперимента падали на отсутствующих `grade`, `PROMPTS`, `FACTS` и старом формате отчёта (`KeyError: records`).
4. GREEN: один общий архив, независимые вопросы, отчёт с обслуживанием, полный HTTP-мок эксперимента.

## Given / When / Then

| Дано | Когда | Тогда |
|---|---|---|
| 12 полных сообщений | Обновляется сводка | 6 старых покрыты summary, последние 6 передаются дословно, архив прежний |
| Менее 10 несжатых | Новый ход | Вызова модели для summary нет |
| Старые tool_calls и результаты | Расчёт границы хвоста | Полный ход остаётся целым, даже если хвост длиннее 6 |
| Прежняя summary | Следующее сжатие | Отправляются прежняя summary и только новый старый префикс |
| Пустая/длинная сводка, tool_calls вместо текста | Попытка сжатия | Граница не сдвигается, старые данные сохраняются |
| Timeout, disconnect, HTTP 503, length | Запрос summary | Один HTTP-запрос, без повтора, ошибка и неизвестный расход учтены |
| Успешный пользовательский ответ и ошибка сжатия | Завершение хода | Ответ и архив сохраняются, показывается предупреждение |
| Архив и summary на диске | Новый экземпляр приложения | Возвращаются тот же архив, summary, граница и хеш |
| Неверный хеш summary | Продолжение диалога | Ошибка до нового платного запроса |
| SQLite v1/v2 | Открытие в D9 | Данные сохранены, новая память изначально пустая |
| Неверная граница при сохранении | Транзакция complete | Старый архив остаётся прежним |
| Один общий диалог | Два режима и 10 вопросов | Одинаковый исходный архив, без подсказок от прошлых ответов |

Регрессионные тесты также покрывают HTTP 4xx/5xx, виды сетевых сбоев, конкурентный доступ, повреждение SQLite, журналы, маскирование ключа, ограничение бюджета и учёт токенов.
