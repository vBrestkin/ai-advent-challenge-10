# BDD

Сначала созданы три Gherkin-сценария в tests/features/agent.feature и тесты
инструментов, ошибок и истории. Первый запуск завершился ModuleNotFoundError
для agent6. Затем реализованы агент, инструменты, HTTP-клиент и интерфейс.

Дополнительный тест показал возможность огромного строкового результата
при Decimal('1e-999999'). После красного теста ограничен диапазон показателя.
Тест экспорта трассы сначала показал отсутствие trace.json, затем экспорт
реализован. Тест пилота проверяет, что пропуск инструментов не засчитывается.

46 тестов проходят. Проверяются 0/1/2 раунда, стек tool_call_id, лимит шагов,
откат незавершённого хода, неизвестные инструменты, неверные аргументы,
деление на ноль, NaN, экстремальный показатель, сетевые ошибки и таймауты,
HTTP 3xx/4xx/5xx, повреждённый ответ, обрезание, отказ журнала, маскирование
ключа, HTTP-интерфейс и неизвестные сессии. Используются Fake и MockTransport.

Реальный пилот выполнен отдельно от автотестов через API веб-приложения.
