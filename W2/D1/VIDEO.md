# Видео дня 6

1. Откройте README и BDD.md. Скажите «Я начал с BDD-сценариев. Агент отдельно
   управляет обращениями к модели и выполнением инструментов».
2. Выполните тесты:

```bash
cd /Users/brestkin/ai-advent-challenge-10/W2/D1
.venv/bin/python -m pytest -v
```

3. Запустите сервер `.venv/bin/agent6`, откройте http://127.0.0.1:8060.
   Если сервер уже запущен, откройте адрес. Не показывайте .env.
4. В новом разговоре задайте «Объясни, что такое JSON, в одном предложении».
   Покажите финальный текст и отсутствие инструментов.
5. В новом разговоре задайте «Посчитай 347 умножить на 29. Используй калькулятор».
   Покажите аргументы и результат calculate, затем ответ 10063.
6. В новом разговоре задайте «Найди сумму заказа A-104 и рассчитай цену
   со скидкой 15%». Покажите find_order с суммой 2390, затем calculate
   с множителем 0.85 и ответом 2031.50. На узком экране прокрутите вниз.
7. Покажите Agent.run(), передачу tool_call_id и повторение цикла.
   Скажите «Модель сама выбирает инструмент и аргументы. Код проверяет их,
   выполняет функцию и возвращает результат модели. Цикл продолжается до ответа».
8. Завершите словами «Проверены все три сценария. История работает в текущем
   процессе. В следующем задании добавлю сохранение после перезапуска».

Три запроса на видео платные. Для воспроизводимой автоматической проверки
можно выполнить `.venv/bin/python -m agent6.pilot`. Это новый реальный прогон
с обновлением submission/pilot.json и trace.json. Неверные сценарии дают код 1.
