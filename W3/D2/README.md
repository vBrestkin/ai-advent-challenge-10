# День 12 · профиль пользователя

В веб-чате можно сохранить две настройки: длину ответа и наличие примера кода. Они хранятся в SQLite отдельно от трёх слоёв памяти дня 11 и передаются модели при каждом запросе, в том числе после вызова инструмента. У каждого разговора свой профиль. Копия разговора получает исходные настройки, которые затем можно менять независимо.

**Как изменить профиль.** Выберите настройки и нажмите «Сохранить профиль» либо отправьте отдельную реплику «Теперь отвечай кратко и без кода». Поддерживаются «отвечай» и «отвечайте», варианты «кратко», «подробно», «с кодом», «с примером кода» и «без кода». Можно указать одну настройку или две через «и» или запятую. Приложение распознаёт целую реплику. Просьба «На этот вопрос ответь кратко» и цитата остаются обычным сообщением.

Изменение применяется уже при ответе на эту реплику. Если включено сохранение, успешный ход и профиль записываются одной транзакцией. При сетевой ошибке или сбое записи сохраняются прежние данные. При выключенном сохранении новая настройка применяется к запросу, а в SQLite остаётся прежний профиль. Загрузка базы дня 11 создаёт поддержку профилей. Старые разговоры открываются с нейтральными настройками.

## Запуск на этой машине

```bash
cd /Users/brestkin/ai-advent-challenge-10/W3/D2
PYTHONPATH=src ../../W2/D5/.venv/bin/python -m pytest -q
PYTHONPATH=src ../../W2/D5/.venv/bin/python -m agent12.web --port 8066
```

Откройте http://127.0.0.1:8066. Команда выше открывает обычную базу дня 12. В VIDEO.md есть отдельная команда, которая открывает копию базы с четырьмя готовыми диалогами для записи.

При чистой установке создайте виртуальную среду и выполните `python -m pip install -e '.[test]'` и `python -m agent12.setup_tokenizer`. Ключ Polza.ai читается из прежних настроек проекта или переменной `POLZA_API_KEY`.

## Как повторить эксперимент

```bash
PYTHONPATH=src ../../W2/D5/.venv/bin/python -m agent12.profile_experiment --budget-rub 20
```

Это новый платный прогон. Он создаёт отдельный каталог в `results/`, четыре разговора в SQLite, точные ответы, CSV и трассу запросов. Программа проверяет два профиля на одном вопросе, изменение предпочтений репликой и десять ответов подряд в одном разговоре. Для проверки длины считаются слова вне блоков кода. Наличие кода определяется по отдельному блоку Markdown. Смысл ответов проверяется отдельно при разборе результатов.

Тесты начинаются со сценария `tests/features/profile.feature`. Покрыты перезапуск и миграция, изоляция и копирование профилей, повторный запрос после инструмента, неоднозначные реплики, три сетевых сбоя, откат при ошибке SQLite, пороги длины и сценарий сравнения. Приложение пишет операции, запросы и ответы в UTF-8 журналы с именами с точностью до секунд. Ключ маскируется.

- `submission/report.md` — итоговая таблица, примеры и выводы.
- `submission/details.csv` и `submission/experiment.json` — точные ответы и результаты по всем вопросам.
- `submission/trace.json` — запросы, ответы API и метрики. Первый прогон находится в `submission/attempt_01/`.
- `VIDEO.md` — команды, действия на экране и готовая речь.
