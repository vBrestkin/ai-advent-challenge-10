# День 15 · что происходит, когда факт устаревает?

В реальном диалоге о демонстрации «Маяка» изменили четыре факта. Агент **4 раза из 4** дал ожидаемый ответ. Ни одного из вытесненных значений не оказалось в проверенных запросах. После завершения задачи рабочая память очистилась. Долговременные факты, решения и журнал восстановились из SQLite.

## Как проверяли

1. Через чат записали исходный срок, версию, требование и подход. Сохранили два решения отдельными записями.
2. По очереди изменили каждый факт и сразу спросили об актуальном значении.
3. После каждого вопроса проверили реальный запрос из журнала HTTP-вызовов. Искали в нём все уже вытесненные значения, а в ответе проверяли наличие актуального значения и отсутствие старых.
4. Передали результат задачи и подтвердили проверку. Сравнили рабочую и долговременную память до и после завершения. Заново открыли приложение и сверили сохранённое состояние.

## Четыре изменения

| Что изменили | Было → стало | Что нашлось в карточке отправленного запроса | Ответ модели | Старое значение в запросе |
|---|---|---|---|---|
| Срок | 2026-12-18 → 2026-12-22 | «Срок»: «2026-12-22» | «2026-12-22» | Нет |
| Версия | v1.2.0 → v1.3.0 | «Версия»: «v1.3.0» | «v1.3.0» | Нет |
| Требование | формат 4K → отменено | «Требование»: «отменено» | «Требование отменено.» | Нет |
| Подход | заранее записанный скринкаст → живая демонстрация | «Подход»: «живая демонстрация» | «Живая демонстрация.» | Нет |

Устаревшее значение названо в **0 из 4 ответов**. В **0 из 4 фактических запросов** найдены вытесненные на тот момент значения. В журнале по каждому изменению есть отметка времени и запись «было → стало».

Принятые решения накопились списком: «Проверить звук перед демонстрацией» и «Подготовить запасной микрофон». Список сохранился после завершения задачи. Ассистент отвечает по активной карточке фактов. Полная история и список решений доступны в интерфейсе. Это разделение важно, потому что свободный текст из прежних записей мог бы повторить старое значение.

## Что очистилось при завершении

| Данные | До подтверждения проверки | После подтверждения и повторного открытия |
|---|---|---|
| Рабочая память | `step = Проверить микрофон` | Пусто |
| Четыре актуальных факта | Срок, версия, отметка об отмене, подход | Совпали с состоянием до завершения |
| Два решения и журнал | Две записи решений и история десяти записей фактов | Совпали полностью |
| Прежняя долговременная карточка | `leader = Ирина` | `leader = Ирина` |
| Этап задачи | Проверка | Завершение |

Автотест отдельно проверяет порядок времени: запоздавшая запись не может восстановить отменённое требование. Другой тест подставляет сбой SQLite при очистке и проверяет откат завершения задачи.
