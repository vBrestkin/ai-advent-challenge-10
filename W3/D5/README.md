# День 15 · актуальные факты и конфликты памяти

В чате «Маяка» можно обновить факт явной репликой. Приложение сохраняет время записи в UTC. В карточке время показывается по Москве.

| Реплика | Что делает приложение |
|---|---|
| `Срок: 2026-12-22` | Сохраняет актуальную дату в формате ГГГГ-ММ-ДД |
| `Версия: v1.3.0`, `Статус: Готово к репетиции` | Заменяет одноимённый факт новым |
| `Требование: формат 4K`, `Отменить требование` | Сохраняет требование или отмечает его отмену |
| `Подход: живая демонстрация` | Обновляет текущий подход |
| `Решение: Проверить звук` | Добавляет запись в список решений |

Приложение распознаёт эти реплики по подписи и двоеточию. Для записи надо оставить включённым «Сохранить вопрос и ответ в диалоге». Запись факта выполняется локально и сохраняется одной транзакцией с репликой. В историю попадают старое и новое значения, ключ и время. Для конфликтующих записей выигрывает более поздняя отметка времени. Сравнение выполняется в UTC, а равная отметка оставляет текущую версию. Отмена сохраняется как запись с пустым значением, чтобы запоздавшее обновление не вернуло требование.

После первой записи такого факта обычный чат этого разговора отвечает по карточке актуальных фактов, профилю и при наличии задачи её этапу и признаку паузы. Полный диалог, список решений, историю замен, тексты карточки задачи и произвольные данные прежних слоёв можно смотреть в интерфейсе. Эти источники не передаются в запросы режима актуальных фактов, поскольку в них могут сохраниться старые формулировки. Новый вопрос передаётся как введён пользователем. Для обычного чата со слоями памяти можно создать другой разговор без команд записи. Копия разговора получает собственную копию фактов и истории. Поле «Статус» в фактах описывает проект, а этап задачи меняется кнопками карточки.

Подтверждение проверки в карточке задачи переводит её в «Завершение» и очищает рабочую память в той же транзакции. Долговременная карточка, актуальные факты, принятые решения, журнал и история диалога остаются доступны. Если запись завершается ошибкой, обе операции откатываются.

## Запуск

```bash
cd /Users/brestkin/ai-advent-challenge-10/W3/D5
PYTHONPATH=src ../../W2/D5/.venv/bin/python -m pytest -q
PYTHONPATH=src ../../W2/D5/.venv/bin/python -m agent15.web --port 8069
```

Откройте http://127.0.0.1:8069. Для чистой установки создайте виртуальную среду и выполните `python -m pip install -e '.[test]'`. Настройки Polza.ai подхватываются из предыдущих дней и переменной `POLZA_API_KEY`.

Команда реального прогона делает четыре платных запроса в пределах заданного бюджета:

```bash
PYTHONPATH=src ../../W2/D5/.venv/bin/python -m agent15.conflict_experiment --budget-rub 20
```

Все операции, запросы и ответы журналируются в UTF-8 `logs/*.log`. Имя файла содержит дату и время до секунд. Ключ маскируется.

- `tests/features/conflicts.feature` — BDD-сценарий замены срока.
- `submission/report.md` — что поменяли, что ушло в запрос и что ответил агент.
- `submission/experiment.json`, `submission/trace.json` — исходные запросы, ответы, состояния и метрики.
- `VIDEO.md` — точные шаги и готовая речь.
