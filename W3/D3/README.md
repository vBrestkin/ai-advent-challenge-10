# День 13 · состояние задачи

В каждом разговоре можно завести задачу. Карточка показывает этап, текущий шаг и ожидаемое действие. Состояние сохраняется в SQLite в таблице `task_states`. Три слоя памяти и профиль пользователя доступны в отдельных разделах.

| Этап | Текущий шаг | Как перейти дальше |
|---|---|---|
| Планирование | Составить и согласовать план | Ввести план и нажать «Утвердить план» |
| Выполнение | Подготовить результат по плану | Описать результат и нажать «Передать результат на проверку» |
| Проверка | Проверить результат по плану | Описать, что проверили, и нажать «Подтвердить проверку» |
| Завершение | Итог сохранён | Действий не требуется |

На любом активном этапе можно нажать «Пауза». Этап, шаг, записи пользователя и признак паузы сохраняются при закрытии приложения. После перезапуска нажмите «Продолжить». На паузе переходы к другим этапам заблокированы.

Состояние меняется через явное действие в карточке. Сервер проверяет текущий этап, паузу, версию карточки и наличие описания в транзакции SQLite до записи. При недопустимом переходе API возвращает HTTP 409 с ожидаемым действием. Устаревшая версия карточки также даёт 409. Чат получает сохранённое состояние для ответа и пояснений. Его сообщения не являются командами записи этапа. Карточка показывает проверенное состояние независимо от текста ответа модели.

В учебном сценарии пользователь сам утверждает план, описывает выполненную работу и отмечает результат проверки. Подтверждение сохраняет его запись о проверке. При создании копии разговора переносятся память и профиль; для копии можно создать свою задачу.

## Запуск

```bash
cd /Users/brestkin/ai-advent-challenge-10/W3/D3
PYTHONPATH=src ../../W2/D5/.venv/bin/python -m pytest -q
PYTHONPATH=src ../../W2/D5/.venv/bin/python -m agent13.web --port 8067
```

Откройте http://127.0.0.1:8067. Команда открывает обычную базу дня 13. В сценарии видео приведена команда для отдельной демонстрационной базы.

Для чистой установки создайте виртуальную среду и установите проект через `python -m pip install -e '.[test]'`. Ключ Polza.ai подхватывается из предыдущих настроек или `POLZA_API_KEY`. Для локальной оценки токенов доступен закреплённый токенизатор через `python -m agent13.setup_tokenizer`.

## Проверки и материалы

- `tests/features/task.feature` — BDD-сценарий восстановления с паузы. Тесты также проверяют пропуски этапов, паузу на каждом из трёх активных этапов, действия в завершённой задаче, разрыв соединения и изоляцию разговоров.
- `submission/report.md` — ход эксперимента, фактическое состояние и ответы модели.
- `submission/experiment.json` и `submission/trace.json` — события обоих типов, расходы и реальные ответы. Первые две попытки сохранены в `submission/attempt_01/` и `submission/attempt_02/`.
- `VIDEO.md` — что открыть, на что нажимать, что произнести.

Для нового платного прогона выполните `PYTHONPATH=src ../../W2/D5/.venv/bin/python -m agent13.task_experiment --budget-rub 20` из папки дня. Создаётся отдельная база и каталог `results/`. Приложение записывает операции и запросы в UTF-8 журналы с именами с датой и временем до секунд. Ключ маскируется.
