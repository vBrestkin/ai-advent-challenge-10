# День 14 · инвариант выбора базы данных

В режиме «Подбор базы данных» ассистент учитывает утверждённую базу для демонстрации проекта. У каждого разговора есть отдельное правило в SQLite, по умолчанию **SQLite**. Можно явно переключить его на **PostgreSQL** через форму. Приложение сохраняет предыдущее и новое значения, время и версию в журнале SQLite. Обновление правила и запись истории выполняются в одной транзакции. Текст в формах подбора и обычного чата не может сохранить новое правило.

## Как работает проверка

1. Сервер читает правило и передаёт его модели в системном сообщении.
2. Модель выбирает `propose` с одной из двух баз или `refuse` с пустым значением. Запрос использует строгую JSON Schema.
3. Сервер проверяет структуру и сравнивает базу в предложении с правилом.
4. Интерфейс получает текст, сформированный из результата проверки. Неожиданные поля, неверный формат, лишние или противоречивые данные приводят к отказу показать предложение.

Проверка охватывает выбор базы в отдельном режиме. Обычный чат, три слоя памяти, профиль и карточка задачи остаются доступны. Форма меняет правило демонстрационного проекта. Само приложение по-прежнему использует SQLite для локального хранения.

Для новой базы разговоров правило создаётся сразу. При открытии базы дня 13 существующие разговоры получают начальное правило SQLite. Копирование разговора переносит действующее значение как начальное для копии.

## Запуск

```bash
cd /Users/brestkin/ai-advent-challenge-10/W3/D4
PYTHONPATH=src ../../W2/D5/.venv/bin/python -m pytest -q
PYTHONPATH=src ../../W2/D5/.venv/bin/python -m agent14.web --port 8068
```

Откройте http://127.0.0.1:8068. Для чистой установки создайте виртуальную среду и установите `python -m pip install -e '.[test]'`. Ключ Polza.ai подхватывается из настроек предыдущих дней или `POLZA_API_KEY`. Токенизатор можно установить командой `python -m agent14.setup_tokenizer`.

Новый реальный прогон платный. Запуск из папки дня:

```bash
PYTHONPATH=src ../../W2/D5/.venv/bin/python -m agent14.invariant_experiment --budget-rub 20
```

Прогон проверяет совместимый запрос, восемь конфликтных формулировок и запрос после явной смены правила. Запросы, ответы, отказы и изменения журналируются в UTF-8 `logs/*.log` с датой и временем до секунд. Секреты маскируются.

BDD-сценарий `tests/features/invariant.feature` проверяет блокировку до показа, когда тестовая модель предлагает PostgreSQL при активной SQLite. Автотесты также проверяют некорректный вывод, сетевой сбой, устаревшую версию, откат при сбое записи журнала, независимость разговоров и восстановление после открытия базы.

- `submission/report.md` — восемь запросов, результаты и выводы.
- `submission/experiment.json` и `submission/trace.json` — исходные ответы, состояния и метрики.
- `VIDEO.md` — что открыть, что нажать и что сказать.
