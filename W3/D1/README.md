# День 11 · три слоя памяти

В одном разговоре веб-чата есть три независимых слоя. Краткосрочная память отвечает за недавние реплики, рабочая хранит текущий шаг задачи, долговременная хранит устойчивые знания проекта.

## Что куда записывается

| Слой | Таблица SQLite | Когда записывается | Что отправляется модели |
|---|---|---|---|
| Краткосрочная | `layer_dialogues` | Успешный ход чата с включённым сохранением, включая вызовы инструментов и результаты | Хвост от шести последних сообщений с границей по началу хода, включая новый вопрос |
| Рабочая | `layer_tasks` | Явная запись по ключу через форму рабочей памяти | Заполненная карточка задачи |
| Долговременная | `layer_projects` | Явная запись по ключу через форму знаний проекта или импорт отобранных Sticky Facts | Заполненная карточка проекта |

В этой версии один разговор связан с одной рабочей карточкой и одной карточкой проекта. «Создать копию» копирует все три слоя. Последующие записи и очистка действуют на выбранный разговор. Поля рабочей и долговременной памяти обновляются явным выбором слоя. Обычная реплика сохраняется в диалоге. Если карточка пуста, её блок отсутствует в запросе.

Эксперимент берёт название проекта и имя руководителя из сохранённых Sticky Facts дня 10. Фразу для начала видео помещает только в диалог, текущий шаг — только в рабочую карточку. Контрольные ответы получены на четырёх независимых копиях состояния. Контрольные вопросы и ответы не записываются. Запросы, ответы и операции приложения журналируются в UTF-8-файлы `logs/*.log` с датой и временем до секунд. Ключ маскируется.

## Запуск на этой машине

```bash
cd /Users/brestkin/ai-advent-challenge-10/W3/D1
PYTHONPATH=src ../../W2/D5/.venv/bin/python -m pytest -q
PYTHONPATH=src ../../W2/D5/.venv/bin/python -m agent11.web --port 8065
```

В браузере откройте http://127.0.0.1:8065. По умолчанию используется рабочая база дня 11. Команда из VIDEO.md открывает базу с сохранёнными копиями эксперимента.

Для чистой установки создайте виртуальную среду, установите `python -m pip install -e '.[test]'` и скачайте токенизатор командой `python -m agent11.setup_tokenizer`. Ключ Polza.ai подхватывается из прежних настроек проекта или `POLZA_API_KEY`. Эксперимент можно повторить командой `python -m agent11.memory_experiment --budget-rub 20`. Это новый платный прогон. Он создаёт отдельную базу и файлы в `results/`.

## Где смотреть результат

- `submission/report.md` — условия, ответы, числа и выводы.
- `submission/details.csv` — одна строка на вопрос и вариант памяти.
- `submission/experiment.json` и `submission/trace.json` — данные завершённого прогона. Первая попытка сохранена в `submission/attempt_01/`.
- `VIDEO.md` — команды для записи, последовательность действий и готовая речь.

BDD-сценарий находится в `tests/features/layers.feature`. Автотесты проверяют восстановление из SQLite, независимость копий, очистку каждого слоя, явное объединение фактов, границу окна, таймаут без записи хода и эксперимент из 12 запросов через HTTP-мок. В комплекте также регрессионные тесты дня 10.
