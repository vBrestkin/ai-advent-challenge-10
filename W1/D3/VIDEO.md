# Сценарий видео D3 с реальным запуском эксперимента

Цель: показать работающий диалог, проверку reasoning и новый полный прогон
четырёх методов на восьми задачах. Готовое видео — примерно 5–7 минут с
ускорением ожидания API. Предыдущий эксперимент занял около 9 минут только
на HTTP-операции; новый может занять другое время.

До записи закройте .env и страницы с ключами. Откройте два окна: редактор
с проектом и терминал. Команды ниже выполняются из папки D3.

## 1. Задача и BDD — около 40 секунд

Кратко обозначьте: 8 задач с эталонами, 4 метода, два thinking-бюджета —
512 и 24576. Это минимальное и максимальное рассуждение; min не называется
выключенным. Общий max_tokens=32768.

```bash
cd /Users/brestkin/ai-advent-challenge-10/W1/D3
.venv/bin/python -m pytest -q
```

Покажите `tests/features/day3.feature` и результат тестов. Объясните, что
тесты написаны до реализации и не расходуют API-баланс.

## 2. Реальный диалог и восстановление истории — около минуты

Выберите новое имя сессии, если video-demo уже использовалось.

```bash
.venv/bin/day3 chat --session video-demo --reasoning max
```

Последовательно введите:

```text
Запомни кодовое слово «Сосна». Ответь кратко.
Какое кодовое слово я попросил запомнить? Ответь одним словом.
/history
/exit
```

Затем запустите ту же сессию и покажите сохранённые сообщения:

```bash
.venv/bin/day3 chat --session video-demo
```

Введите `/history`, затем `/exit`. Покажите модель, режим и лимит в начале
сессии. Эти два сообщения — реальные платные обращения; просмотр истории
и повторное открытие сессии без сообщения не генерируют ответ модели.

## 3. Проверка модели и свежий пилот — около минуты

```bash
.venv/bin/day3 catalog
.venv/bin/day3 pilot
```

В каталоге покажите модель, закреплённый маршрут, поддержку reasoning и
json_schema_strict. Пилот отправит два настоящих запроса. Покажите счётчики
reasoning_tokens, стоимость и строку «Режимы подтверждены: да».

Скопируйте полный путь к НОВОМУ pilot.json из терминала. Если пилот не прошёл,
покажите причину и остановите демонстрацию до выяснения — проверку не обходите.
История про прежний off-пилот необязательна; достаточно назвать текущие режимы min/max.

## 4. Новый полный эксперимент — запуск в кадре, ожидание ускорить

Вместо пути-заглушки вставьте путь, напечатанный на предыдущем шаге:

```bash
.venv/bin/day3 experiment --pilot "/полный/путь/к/новому/pilot.json" --budget-rub 20
```

Бюджет 20 ₽ выбран для демонстрации с запасом на резервы неизвестных списаний.
Это локальный предел учёта, а не заранее списываемая сумма. Команда выполняет
новый прогон: 64 комбинации и до 80 платных вызовов.

Покажите первые строки прогресса, затем ускорьте запись ожидания. Во время
ожидания можно показать `TASKS.md`, `METHODS`, `MODES` и `solve_one` в
`src/day3/experiment.py`. Обратите внимание на два хода metaprompt и три роли
одной модели в experts. Не меняйте промпты или настройки посреди прогона.

Верните обычную скорость перед окончанием, покажите 64/64 и путь к новому
report.md. Если запись остановлена через Ctrl+C, продолжите тот же набор:

```bash
.venv/bin/day3 experiment --pilot "/тот/же/pilot.json" --budget-rub 20 --resume "/папка/этого/прогона"
```

При продолжении бюджет остаётся прежним, выполненные попытки не повторяются.
Если достигнут бюджетный предел, повтор той же команды сам по себе его не увеличит.

## 5. Результаты именно нового прогона — около минуты

Откройте report.md из папки, которую напечатала команда, и соседние summary.csv
и interactions.csv. Не подменяйте свежие результаты старой таблицей из submission/.

Покажите:

- верные ответы, токены и время в min/max;
- оба вызова в расходах metaprompt;
- ошибки API отдельно от неправильных ответов;
- известную стоимость отдельно от резерва;
- прирост относительно прямого ответа на одинаковых сопоставимых задачах.

При сетевых сбоях используйте число сопоставимых задач из interactions.csv.
Фраза «все полученные ответы верны» отличается от «модель решила все восемь задач».

## 6. Выводы — 40–60 секунд

Произнесите речь, подготовленную в чате. Перед записью этой части сверьте
её цифры и выводы с НОВЫМ прогоном: результаты могут отличаться.
Текст речи в этот файл не сохраняется.
