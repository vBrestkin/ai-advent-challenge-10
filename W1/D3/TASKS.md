# Восемь задач D3 и эталоны

Эталоны доступны проверяющему коду, но не передаются модели.

## T1. Рыцари и лжецы

Каждый из A, B, C, D — либо рыцарь (всегда говорит правду), либо лжец (всегда лжёт). A: «B — лжец». B: «C и D одного типа». C: «A и B — лжецы». D: «Ровно один из A и B — рыцарь». Назови всех рыцарей латинскими буквами через запятую.

Эталон: `A,D`.

## T2. Двоичные строки

Сколько двоичных строк длины 12 содержат ровно пять единиц, причём никакие две единицы не стоят рядом? Ведущие нули разрешены. Ответ — целое число.

Эталон: `56`.

## T3. Ровно один делитель

Сколько целых чисел от 1 до 1000 включительно делятся ровно на одно из чисел 6, 10, 15? Числа, делящиеся на два или три указанных делителя, не учитывай. Ответ — целое число.

Эталон: `233`.

## T4. Рюкзак

Вместимость рюкзака 15. Предметы (вес, ценность): A=(3,4), B=(4,5), C=(5,7), D=(8,12), E=(9,13). Каждый можно взять не более одного раза. Найди максимальную суммарную ценность без превышения вместимости. Ответ — только целое значение максимальной ценности.

Эталон: `21`.

## T5. Условная вероятность

Абстрактное событие происходит с вероятностью 1%. Детектор положителен с вероятностью 90%, если событие произошло, и с вероятностью 5%, если оно не произошло. Результат положительный. Какова вероятность события при этом условии? Ответ — точная дробь p/q.

Эталон: `2/13`.

## T6. Возрастающая подпоследовательность

Найди длину самой длинной строго возрастающей подпоследовательности массива [3,4,-1,0,6,2,3,7,5,8,9,1]. Элементы не обязаны стоять подряд, исходный порядок сохраняется. Ответ — целая длина.

Эталон: `7`.

## T7. Доли по сегментам

У алгоритма A в простых случаях 81 успех из 87, у B — 234 из 270. В сложных случаях у A 192 из 263, у B 55 из 80. Кто имеет более высокую долю успеха: в простых, в сложных и суммарно? Суммарно складывай успехи и попытки, не усредняй проценты. Ответ — три латинские буквы через запятую в указанном порядке.

Эталон: `A,A,B`.

## T8. Расписание

Есть два одинаковых исполнителя; каждый выполняет не более одной задачи одновременно. Задачу нельзя прерывать или выполнять вдвоём. Переключение мгновенно, начало времени 0. Длительности и предшественники: A=3 (нет), B=5 (нет), C=4 (A), D=6 (A), E=4 (B,C), F=3 (D,E). Задача может начаться только после завершения всех предшественников. Найди минимальное время завершения всех задач. Ответ — целое число.

Эталон: `14`.

Дроби сравниваются по точному значению. Для T1 порядок букв не важен; для T7 важен.
