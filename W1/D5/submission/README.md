## Наблюдения при проверке данных

Запрошенный маршрут во всех вызовах — `google-ai-studio/flex`, fallback
отключён. Идентификаторы моделей подтверждены ответами. Поле фактического
backend `provider` во всех 75 ответах отсутствует; оно сохранено как неизвестное,
а не подменено названием запрошенного маршрута.

Стоимость `usage.cost_rub` в части ответов на 1% ниже простого расчёта по
снимку каталога, в остальных совпадает с ним с точностью округления.
Причина этой разницы не установлена. В таблицах — цена из API, которую
[документация Polza.ai](https://polza.ai/docs/osobennosti/usage) описывает
как уже списанную стоимость. Баланс личного кабинета отдельно не сверялся.

Reasoning-токены входят в completion/total. Они не прибавлялись к total ещё раз.
Фактическое число thinking-токенов могло превышать запрошенные 1024;
одинаковые параметры не означают одинаковый фактический расход.
