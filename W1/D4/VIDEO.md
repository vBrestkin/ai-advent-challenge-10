# Видео D4: запуск реального эксперимента (примерно 4–6 минут)

Закройте .env и страницы с ключами. Нужны терминал и редактор проекта.

## 1. Задача и тесты — 30–40 секунд

Покажите tests/features/day4.feature: два запроса, три температуры, пять
повторов. Объясните, что сначала написаны тесты, затем реализация.

```bash
cd /Users/brestkin/ai-advent-challenge-10/W1/D4
.venv/bin/python -m pytest -q
```

## 2. Температура в диалоге — около минуты

Для новой демонстрации выберите новое имя разговора, если это уже использовалось.

```bash
.venv/bin/day4 chat --session video-day4 --temperature 0
```

Введите сообщение, затем `/history` и `/exit`. Повторно откройте ту же сессию:

```bash
.venv/bin/day4 chat --session video-day4
```

Покажите восстановленные температуру 0 и историю. Введите `/history`, `/exit`.
Сообщение модели платное; просмотр истории не запускает генерацию.

## 3. Новый эксперимент — запуск в кадре

```bash
.venv/bin/day4 catalog
.venv/bin/day4 experiment --repeats 5 --budget-rub 5
```

Покажите поддержку temperature и reasoning. Во всех запросах один бюджет
thinking 512 и max_tokens=4096. Меняется только температура: 0, 0.7, 1.2.
JSON задан промптом, строгая схема API не используется.

Запуск делает 30 настоящих платных вызовов и печатает прогресс. Покажите
начало, при необходимости ускорьте ожидание. Перед окончанием верните обычную
скорость и покажите 30/30 и путь к новому report.md. Если пришлось прервать:

```bash
.venv/bin/day4 experiment --repeats 5 --budget-rub 5 --resume "/папка/этого/прогона"
```

Готовые попытки не повторяются. Бюджет остаётся прежним. Если достигнут
бюджетный предел, повтор команды с тем же пределом сам по себе его не увеличит.

## 4. Результаты нового прогона — около минуты

Откройте report.md и summary.csv из папки, которую напечатала команда,
а не прежние файлы submission/.

Покажите:

- правильность математического ответа и ошибки формата отдельно;
- количество полученных ответов и ошибки API;
- исходные ответы при одинаковой температуре;
- число различных названий и нормализованных наборов;
- сходство Жаккара: высокий показатель означает больше совпадений;
- время, токены, известную стоимость и резерв неизвестных списаний.

Перестановка тех же пяти названий не считается новым набором. Если число
полученных списков отличается, сравнивать только размеры пулов некорректно.

## 5. Выводы — 30–45 секунд

Возьмите цифры именно нового запуска. Объясните, где разнообразие полезно
для генерации, а где изменение единственного верного числа является ошибкой.
Проверьте, увеличилось ли разнообразие при переходе 0.7 → 1.2, не утверждайте
это заранее. По T=0 сообщите число совпавших полученных ответов; не выдавайте
несколько совпадений за универсальную гарантию повторяемости.

В конце покажите .log с датой до секунд. Повторный experiment создаёт
новую платную выборку; результаты могут отличаться от предыдущих.
